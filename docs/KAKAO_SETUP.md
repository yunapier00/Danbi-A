# 카카오톡 챗봇 연결 가이드

단비 서버의 `POST /api/kakao/skill`을 카카오 i 오픈빌더의 **스킬**로 연결한다. 서버 쪽 구현은
`danbi/api/kakao.py`(엔드포인트)와 `danbi/api/kakao_format.py`(응답 변환)이다.

## 동작 요약

- **인증:** 카카오 스킬 요청에는 서명이 없다. 스킬 설정의 헤더 `X-Danbi-Kakao-Secret`에 넣은 값이
  환경 변수 `KAKAO_SKILL_SECRET`과 같을 때만 처리한다(다르면 401). 환경 변수가 없으면 엔드포인트 자체가 없다(404).
- **5초 제한 → 콜백:** 스킬은 5초 안에 답해야 하는데 답변은 보통 5~30초 걸린다. 요청에 `callbackUrl`이 있으면
  즉시 "자료를 찾아보고 있어요"(`useCallback: true`)로 답하고, 답이 나오면 그 URL로 보낸다(5분간 1번만 유효).
  콜백 주소는 `kakao.callback_hosts`(기본 `kakao.com`, `kakaoenterprise.com`)의 https 주소만 호출한다.
  콜백이 없으면 `kakao.sync_timeout`(4.3초) 안에 끝날 때만 답하고, 나머지는 "잠시 후 다시 물어봐 주세요"로 답한다.
  **그래서 콜백 기능을 반드시 켜야 한다.**
- **사용자와 대화:** 카카오 사용자 키(`userRequest.user.id`)는 저장하지 않고, `KAKAO_USER_SALT`로 해시한
  `kakao:…` 키로만 쓴다. 대화 기록(최근 10턴, 1시간), 분당 제한, 하루 제한이 이 키 기준이다.
  "새 대화"(바로가기 버튼)를 보내면 대화 기록을 지운다.
- **하루 3회 제한:** `limits.per_user_per_day`(기본 3). 웹은 IP, 카카오는 사용자 키 기준으로 추적 DB에서 센다
  (한국 시간 자정에 초기화, 서버를 재시작해도 유지). 넘으면 안내 문구로 답하고 답변 끝에 "오늘 남은 질문: n회"를 붙인다.
- **응답 형식:** 카카오 말풍선은 마크다운을 못 그리므로 일반 텍스트로 바꾼다(표 → `• 항목: 값`, 제목 → `■`).
  말풍선은 최대 3개(1,000자씩)이고, 출처가 있으면 마지막 말풍선이 "원문 링크" 카드(버튼 최대 3개)가 된다.
- 개발자 페이지(`/dev`)의 채널 필터에서 "카카오"로 기록을 볼 수 있다. 실행 상세에 사용자 키(해시)가 보인다.

## 서버 설정 (Railway Variables)

| 이름 | 값 |
|---|---|
| `KAKAO_SKILL_SECRET` | 긴 무작위 문자열. `python -c "import secrets; print(secrets.token_urlsafe(32))"` |
| `KAKAO_USER_SALT` | (선택) 사용자 키 해시용 다른 무작위 문자열. 없으면 `KAKAO_SKILL_SECRET`을 쓴다. **한 번 정하면 바꾸지 말 것** (바꾸면 모든 사용자의 대화·횟수가 새로 시작된다) |

배포 후 확인 (비밀값이 없으면 404, 틀리면 401이어야 한다):

```
curl -i -X POST https://<도메인>/api/kakao/skill -H "Content-Type: application/json" -d '{}'
```

## 카카오 쪽 설정

1. **카카오톡 채널 만들기:** [카카오톡 채널 관리자센터](https://center-pf.kakao.com)에서 채널 개설.
   검색 허용·공개 설정은 테스트가 끝난 뒤 켠다.
2. **챗봇 만들기:** [카카오 i 오픈빌더](https://chatbot.kakao.com)에서 카카오톡 챗봇 생성 → 위 채널 연결.
   (오픈빌더 이용 신청이 승인돼야 한다.)
3. **스킬 등록:** 스킬 → 생성
   - URL: `https://<도메인>/api/kakao/skill`
   - 헤더: `X-Danbi-Kakao-Secret` = `KAKAO_SKILL_SECRET`과 같은 값
4. **폴백 블록에 연결:** 시나리오 → 기본 시나리오 → **폴백 블록**
   - 파라미터 설정에서 위 스킬 선택
   - 봇 응답을 **스킬데이터 사용**으로 설정
   - 모든 질문이 폴백으로 들어오도록 다른 블록(웰컴 블록 제외)은 만들지 않는다.
5. **콜백 켜기:** 설정 → **AI 챗봇 관리**에서 AI 챗봇 전환을 신청한다(승인까지 시간이 걸릴 수 있다).
   승인되면 폴백 블록 설정에서 **Callback 설정**을 켠다. 이게 꺼져 있으면 대부분의 질문이 "잠시 후 다시"로 끝난다.
6. **웰컴 블록(선택):** "단국대학교 비서 AI 단비예요. 하루 3번까지 질문할 수 있어요." 같은 안내와 예시 질문 바로가기.
7. **배포:** 오픈빌더 상단의 배포 버튼. 설정을 바꿀 때마다 다시 배포해야 반영된다.

## 테스트할 때 주의

- **봇 테스트 창에서는 콜백이 동작하지 않는다.** 실제 카카오톡에서 채널을 친구 추가한 뒤 대화로 확인한다.
- 질문 하나하나가 실제 API 비용이고 하루 3회 제한에도 걸린다. 테스트 중에는 `config/settings.yaml`의
  `limits.per_user_per_day`를 잠시 올리거나, 개발자 페이지에서 남은 횟수를 확인한다.
- 실패하면 개발자 페이지에서 채널 "카카오"로 실행 기록을, Railway 로그에서 `카카오 콜백` 경고를 확인한다.
